# v0.5.6 同步日常行动与参战延后扣点

- 每个时间回合仍各有3日常点，分3轮同步提交；每轮每单位提交一次，御主和从者可直接切换并分别提交，不必等待其他人的顺序。
- 收齐行动后统一结算；移动先结算，同类行动冲突采用固定单位顺序。未结算的计划只对所属玩家可见。超时只为尚未提交的单位补待机，不丢弃已提交计划。
- 待机只消耗当前1点。休眠、工房等多点动作保留原费用，并占用对应的连续轮次。
- 发起战斗本身不扣日常点，也不另占一次日常提交。战斗结束后，实际参战的御主和从者各扣下一次日常行动的1点并跳过该次；若该次已提交但未执行，则替代该计划。没有可用日常行动时，费用保留到之后的行动机会。每场战斗只记一次，纯AI快速战斗同样适用。
- 令咒攻击+15、防御+15仅作用于契约从者；从御主界面使用也不会强化御主本人。
- Render部署配置保留；离线试玩单文件已重新生成。旧版已开始的房间需要新建，本次按要求未继续运行测试。

# v0.5.5 宝具先引导、后选点

攻击宝具先付魔力并完成引导，进入“选择目标地点”，不预存落点；选点不另扣AP/MP。无独立引导数的攻击宝具按其原行动消耗完成准备。选错空格或范围内无人时保留待释放状态，可以重新选点。引导/待释放时被攻击仍会中断。令咒完成引导后可立即选点；反击宝具直接与当前攻击者交锋。

同时保留v0.5.4私密掷骰和纯AI快速结算。

# v0.5.4 私密掷骰与AI快速结算

属性对抗只向玩家展示自己的骰子数量、点数、修正与成功/失败；敌方对抗骰子和实际属性等级从接口、待应对记录和战报隐藏。最近两次结果保留在战斗图上。

纯AI双方战斗立即结算，各50%胜率；rd75定义为1至75均匀随机整数。按当前生命扣除：胜者损失r%，败者损失2r%，生命最低0。参战主从按阵营共同结算，各按自己的当前HP扣除相应百分比；未参战伙伴不受伤。双方可能均存活，结算后继续日常；涉及真人的战斗仍走正常流程。

# v0.5.3 移除防御动作，加入反击

删除无规则依据的“1AP防御+6减伤”按钮和AI动作。遭受攻击时，可在开始属性应对前选择0AP、1士气反击；比较双方伤害，较低方承受差值，不可再次应对、士气改判或连锁反击。攻击技能仍支付MP与冷却；按本次指定，宝具反击用令咒立即释放，至少1划，每划抵消最多4引导动作。双方相等则互不造成伤害；既有护盾可吸收差值。范围攻击只处理当前受击者交锋，其他目标继续，不自行推演额外对波波及。

# 冬木圣杯战争 v0.5 · Render跨WiFi版

七人同步提交日常行动、各自为战的网页战棋。包含369张Mooncell七职阶改编卡和7张原模板、固定效果技能/宝具库、自建从者、主从独立单位、令咒、13地点树状地图和圣杯仪式终局。

## 玩游戏

- 单机：打开 dist/冬木圣杯战争-离线试玩.html，点击演习，依次占职阶、选卡或建卡、准备、AI补位开始。
- 七人跨WiFi：按 [Render部署说明](docs/RENDER.md) 将项目部署到同一个HTTPS网址，创建房间并分享房间码。
- 本机服务器：安装Node.js 24，在本目录执行 npm start，打开 http://localhost:3000。没有外部npm依赖，不需要npm install。

Render免费试玩使用 render.yaml，重启/重新部署可能丢房间。长局可选 render-persistent.yaml，需在自己的Render账号确认持久存档方案和费用。本包未代替你创建Render服务，没有附带已发布的公网网址。仅运行一个Node服务实例。

## 本次规则

- 主从各自每时间回合3日常点，一天4个时段，战斗每回合2AP。
- 普通移动、后撤、冲锋、边缘脱战分开。地面被周身限制时须后撤；阻断使后撤费用变为2AP。
- 飞行有高度和开关费用，忽略周身与地形阻拦，但不允许棋子重叠；攻击距离计算高度差。
- 防守者、攻击者依次选属性，攻击成功0/1/2次对应0%/50%/100%。对抗后防守者可手动用1士气挽回一次失败。
- 零士气再承受士气扣除时扣20MP，缺口双倍扣HP，按用户本次指定。
- 从者6点、御主9点预算固定，专属点可换通用；通用奖励不能换专属。部分职阶特性按数据库优惠价。
- 令咒日常/战斗均可使用，含仅限从者的攻击+15、防御+15、回复60HP/MP、强制应对/命中、传送、双人脱战、缩短宝具引导。
- 剩余两名从者时圣杯随机显现并公开；持杯不能位移，仪式须完整度过下一个时间回合，战斗会打断。

完整规则与取舍见 [v0.5改动清单](docs/V05-CHANGES.md)，也可打开游戏内规则手册。地图分四时段显示，支持本机更换底图；攻击技能和宝具有同步视觉特效，支持系统减少动态效果偏好。
