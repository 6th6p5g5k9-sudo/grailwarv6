# 技能和人物编辑器

- 新建技能仍可自由起名；技能、资源及词条的内部编号自动生成。
- 已有技能和宝具通过搜索列表选择。名称、效果说明均支持包含匹配，不必输入前缀或精确名称；效果、代价资源等下拉框也支持中文关键词搜索。
- 搜索框支持方向键、回车选择和 Esc 关闭。清除此栏会撤销已有库技能的选用。
- 多词条技能提供可视化表单：独立时机、事件、嵌套条件、代价、变量、累计阈值、效果、叠加、计时及次数限制。可复制、删除和排序词条与效果。
- 公式使用数值节点组合：固定数值、数值引用、二元运算、取整、最值及百分比等。引用从已有资源、计数器和当前词条的变量中选择。
- JSON 为可选高级入口，原始数据中的未编辑字段保留。修改高级 JSON 后，图形表单暂时停用，应用或还原后恢复；保存和沙盒沿用现有解析入口。
- 未接入的效果、反应窗口仍按原注册表标记和限制，编辑器不改变执行规则。尚未接入的交互节点及部分原有高级字段只保留原配置，未增加专用输入表单。
- 人物编辑器显示预算、技能栏位及由现有建卡函数生成的属性预览；校验或保存失败保留填写内容。

本轮按用户要求不运行测试套件；完成 JavaScript 语法、离线脚本语法、构建和差异空白检查。尚未进行浏览器交互回归。
