# Render 跨 WiFi 部署 · v0.5

不同 WiFi 的玩家访问同一个 HTTPS 网址，使用同一房间码即可。无需处于同一局域网，也无需端口映射或把自己家里的公网 IP 发给朋友。

## 最少操作：免费试玩版

1. 在自己的 GitHub 账号建立私有仓库，把本包 grail-war 目录内文件上传到仓库根目录（package.json、Dockerfile、render.yaml 应处于根目录）。不要上传 data、reference、research 或旧压缩包。
2. 登录 Render，选择 New → Blueprint，连接该仓库，应用 render.yaml。配置为 Docker Web Service、免费实例，健康检查 /api/health；免费方案不挂磁盘。
3. 部署成功后复制 Render 提供的 https://…onrender.com 地址。所有人打开这个地址，房主创建房间，其他人输入房间码加入。
4. 七人各用自己的设备、浏览器或独立隐私窗口；同一浏览器同一网站的身份保存在本机，不能用普通标签页扮演多个人。

免费 Render 服务可能休眠，首次打开较慢；免费实例的本地房间在重启、重新部署时丢失。长局请使用下面的持久化配置。免费额度和服务价格以 Render 当时显示为准，本包不替你购买服务。

## 保留长局存档：可选付费持久化

在 Render 后台将实例改为支持磁盘的方案，添加磁盘挂载 /app/data，环境变量 DATA_DIR=/app/data。也可使用 render-persistent.yaml 中的配置替换 render.yaml 后部署；确认 Render 显示的费用后再创建。

仅运行一个服务实例；本版文件房间仓库不支持多实例并发共享。不要在 Render 设置自动多实例扩容。

## 数据与隐私

服务只处理虚构御主代号、虚构角色资料、房间身份令牌、游戏存档；没有真实地址、GPS、通讯录、邮箱或密码输入项，不读取浏览器定位，不主动记录客户端 IP，也没有第三方统计或字体请求。角色公开简介会展示给同局玩家，勿填写现实住址等私人资料。Render 本身可能按其隐私政策保留基础设施访问日志。

身份令牌仅放在浏览器本机与服务端存档；不会进入公开战局、邀请链接或战报。房间码可分享，令牌和 data 存档不可分享。服务器只公开 public 目录，不公开存档、附件或部署环境变量。使用 Render 自带 HTTPS，不要给玩家发管理后台或仓库密钥。

## 本机运行

安装 Node.js 24，解压后在项目目录执行 npm start，打开 http://localhost:3000。HTML单文件仅供本机AI演习，七人跨网请使用服务器部署网址。
