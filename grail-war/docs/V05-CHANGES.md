# v0.5 · 功能清单与规则取舍

## 原有五项

1. 369 张 Mooncell 七职阶可召唤卡（泳装、Alter、不同灵基分别计卡）及 7 张原模板；职阶先到先得，再选角色。来源修订信息仍保留。技能库1453项、宝具库412项。
2. 从职阶、特性和库内固定效果创建从者；可编辑人物姓名、简介、技能/宝具名称和渊源，不能上传效果代码或任意费用。
3. 主从各为独立单位；御主目前接入10项御主库技能，支持固定9点特性与令咒。令咒日常/战斗均可使用，攻击+15、防御+15、回复60HP/MP等沿用既有规则。
4. 剩余两名从者时圣杯随机显现、全图播报与实时定位；可拾取与放下，持杯无法移动、后撤、调整高度、传送或撤退。仪式从下个完整时间回合开始计，到该回合结束获胜；战斗立即中断。
5. 13 地点树状夜景图；玩家可更换本机底图，不改变规则标记。

## 本次更改

- 士气：脱战通常减少1；偷袭者脱战减少2。每一次应扣士气若当前已为0，扣20MP，不足部分双倍扣HP：15MP/0士气扣后为0MP、损失10HP。这采用本次用户指定，覆盖原书“没有则不再扣取”的脱战条文。
- 手动应对：两个属性对抗完成后，防守者可选消耗1士气挽回一次失败，只改一次；也可保留，或预设自动应对。零士气不能主动选择强化。
- 后撤与脱战是两个动作：相邻敌人周身内禁止普通移动，后撤固定一格，通常1AP，受阻断时2AP。脱战仍须先到地图边缘。
- 飞行：通用特性2点/层，高度上限每层1；1AP调整高度。飞行忽略周身和地形阻挡，棋子仍不能重叠。攻击距离采用平面横纵/斜向格距加高度差；不是飞行后任意无限射程。禁空领域采用“同战场敌方全部禁飞”的本版固定变体；无飞行敌人时转阻断。
- 周身：默认一圈（半径1）；一人成军在无契约友军参战时半径+1。横扫、阻断、援护等复用周身/距离机制。
- 特性点：初始从者6点、御主9点保持固定；各自专属预算可购买通用特性；战斗专家奖励与战斗中获得的通用点不能反购专属。Saber/Lancer/Berserker的阻断、Saber/Berserker的横扫按数据库优惠价校验。
- 地图：白昼Ⅰ、白昼Ⅱ、黑夜Ⅰ、黑夜Ⅱ有不同光照、色调和战斗图底色，自定义底图同样受时间表现影响。
- 技能方向：群体增益、护幕、削魔、嘲讽、自损、持续中毒/灼烧/诅咒、特攻、穿防和命中回魔分别结算。部分代表宝具增加直线、领域、自我牺牲等机制。
- 视觉：发动事件在七人战局同步；剑光、箭雨、枪击、光束、火焰、雷光、寒冰、暗影、魔术阵、领域有不同配色和表现。支持系统减少动态效果偏好；不阻塞操作和服务端结算。
- 部署：提供 Render 免费试玩与可选付费持久化配置；所有人访问同一个HTTPS网址即可跨WiFi游戏。无须暴露家庭地址或家庭公网IP。

## 实际边界

新增卡依旧是原作效果方向的战棋改编，不能等同于369张已经逐条人工审定的极简杯卡。同名数据库技能尚未全面覆盖；御主库不是完整数据库；濒死令咒沿用治疗、回魔、防御的自动预案。新增禁空领域范围是已说明的固定玩法变体。

本包未代为在你的Render账号创建服务，也不包含已发布的公网网址。部署操作见RENDER.md。免费实例重启会丢房间，长局需自行确认持久存档方案和费用。
