# v0.3 验证记录

2026-11-23。

32 项核心/API 测试通过：

- 保留每日4时间回合、每回合3日常点与独立2战斗点。
- 九节点八条边，连通无环；禁止无道路的地理相邻移动。
- 四种双向发现组合，1d20−目标灵格＋目标遮蔽的严格阈值；离开失位；查询不重掷。
- 未发现角色的位置/数值、其他玩家发现关系、私人日志与战斗区域不通过接口泄露。
- 无定位不能交战；单向发现才可偷袭；参战费用每人一次、最低0。
- 真正等待防守者与攻击者依次选择，拒绝错误身份代选；双方使用自己的属性数量d6。
- 0/1/2次攻击成功的0/50/100%最终伤害，减伤先算、护盾最后吸收。
- 骑士王技能补齐；同名技能映射到所提供数据库原文。
- 魔力放出费用、四选一数据；对魔力与骑乘的零动作/轮次/每战次数；领袖气质的整场与每日限制；龙之炉心；黄金律；心眼的递增费用；直感d6免疫；无穷武炼的整局次数和双方消加值；精神污染的控制动作；日常阵地。
- 偷袭敏捷、部位前置与暴露；超时备用选择不重复扣攻击费用。
- 三场完整AI战争无死锁或负数资源。
- 房主改灵格的权限，御主供魔日结与同意供魔、龙炉心/阵地耗魔联动。
- 横扫与冲锋，以及精神污染固定魔力对抗中的无穷武炼窗口。

七个隔离浏览器验证：房主修改灵格、展开数据库原文；独立发现视角、树线、偷袭按钮权限；400格战斗中实际先由防守者点击属性、再由攻击者点击属性；伤害比例战报；魔力放出x和四选项表单；局外浏览器及其API响应无战斗定位；刷新重连；390/768/1440视口无页面横向溢出；离线版同样使用本人的私有视角；没有浏览器脚本异常。

浏览器用合成房间固定四种发现前提，避免概率导致端到端测试偶发失败；随机发现本身另由核心测试覆盖。环境禁止file://导航，离线单文件通过独立HTTP承载验证。未做真人长期平衡、弱网/大量房间或公网部署测试。
